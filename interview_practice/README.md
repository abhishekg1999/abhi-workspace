#how to enable line number in vi editor
# first of all check the .vimrc file in present or not in your home directory
#if yes then keep the line "set nu" in .vimrc file 
#if .vimrc file not present then create it and keep bellow lines 
set nu
set ai
set tabstop=4
set ls=2
set autoindent
# now open any file with vi you will get line numbers
