## how the bubble and selection short works 

int a[] = {9,3,5,2,6,1,4,8,7};

bubble sort:
after iteration-1 => a[3,5,2,6,1,4,8,7,9]

note:
builds the sorted list from the back to the front (putting the largest elements at the end first)

selection sort:
after iteration-1 => a[1,9,5,3,6,2,4,8,7]

note:
builds the sorted list from the front to the back (putting the smallest elements at the beginning first)
